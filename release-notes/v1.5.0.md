# v1.5.0 — every left-rail defect fixed, 140 lines lighter

**Install or upgrade:**

```bash
dsh plugin --profile web add dsh-chat-locator
```

Then restart `dsh web` once. Settings already live in your browser since 1.4.0, so there is nothing to migrate.

### Fixed (each one reproduced before it was changed)

* **Left mode was effectively invisible.** The override placed the rail at about -20px — outside the chat column, where sticky layout clips it. It now mirrors the built-in `left: 12px`.
* **Left ticks were ragged.** Only `::before`'s `left` was mirrored, not `transform-origin`, so normal and unloaded ticks were indented by different amounts.
* **The left hover/click target collapsed to zero width**, which made ticks hard to hit and pushed the focus ring outside the chat area. The button keeps the full frame width and the ring mirrors to the left edge.
* **Hovering the current turn wiped the whole gradient.** The built-in rail sets `markActive` *or* `markPreview` (never both) and the gradient anchor only knew the latter. The anchor is now `:is(.…_markPreview, .…_mark:hover)`.
* **A larger preview font clipped its last line** — the height formula forgot the prompt line (7px short at 18px / 6 lines). It now accounts for it: 100 / 148 / 217 / 58.
* **Settings changes were never persisted.** `update()` mutated the snapshot object in place, `createSnapshotStore` deep-freezes it, and zustand short-circuits on `Object.is` — so nothing was written and a reload reverted every change. Writes now copy the record first.
* **Corrupt stored JSON** (`null`, `[]`, a string) made the settings store throw; there is a type guard now.
* **A 400 ms rescan window could swallow a late mount** — a rail arriving inside the window and then never changing missed the override for good.
* **Remounting stacked a second `<style>`**, and a tag removed by someone else stayed gone. It is replaced now, and re-attached when missing.
* **Diagnostics could report a stale prefix** after the rail unmounted.
* **The preview enter animation depended on stylesheet order**; it now uses its own `@keyframes` name, `!important`, and a reduced-motion guard.

### Changed

* **One table, one policy.** Four parallel field lists and a three-layer store collapsed into `FIELDS` + `createSettingsPolicy()`: default, range, step, normalization and UI row for a setting now come from a single place. `client.js` 970 → 830 lines, `index.js` 32 → 14.
* **"Restore defaults"** writes one empty user layer instead of unsetting fields one by one, which also drops stale and unknown keys.
* **Tests: 118 → 151 assertions.** The stubs now model `createSnapshotStore` faithfully (deep freeze, same-reference short circuit, persist on notify) and assert the stub contract itself, so this class of bug cannot hide again.
* Docs (README, design notes, CONTRIBUTING, SECURITY, templates) rewritten for 1.5.0 and trimmed; `design-notes` 522 → 273 lines.
* `package.json` no longer injects `@deepseek-ai/dsh-client-runtime`, which does not exist in dsh 0.2.1-rc.2.

### Notes

* Zero runtime dependencies, no build step. Requires dsh 0.1.7 or newer.
* `npm test` runs `node --check` on both halves plus **151 assertions**, with nothing installed.
* Published to npm with a provenance attestation (Sigstore transparency log).

## dsh-chat-locator v1.5.0（简体中文）

**安装或升级：**

```bash
dsh plugin --profile web add dsh-chat-locator
```

装完重启一次 `dsh web`。设置从 1.4.0 起就住在浏览器里，没有别的要迁移。

### 修复（每一条都先复现、再改）

* **左置模式基本不可见**：覆盖样式把定位条推到约 -20px，落在对话区之外，被 sticky 布局整体裁掉；现在镜像内置的 `left: 12px`。
* **左侧刻度参差**：只镜像了 `::before` 的 `left`，没镜像 `transform-origin`，普通刻度与未加载刻度的缩进不一致。
* **左置时悬停/点击面塌成 0 宽**：按钮宽度被压没、键盘焦点环画到对话区外；现在按钮保留整帧宽度，焦点环镜像到左端。
* **悬停当前轮时整段渐变消失**：内置定位条只加 `markActive` 或 `markPreview`（二选一），旧锚点只认后者。
* **预览字号放大后裁掉最后一行**：高度公式漏算提示词行高（18px / 6 行实测裁掉 7px），现改为提示词行高 + 正文行高 × 行数。
* **设置改动根本不落盘**：`update()` 就地修改快照对象，而 `createSnapshotStore` 会深冻结入参、zustand 又按 `Object.is` 短路 —— 不通知也不落盘，刷新即回滚。现在写入前一律复制记录。
* **损坏的存量 JSON**（`null` / `[]` / 字符串）会让设置构造抛错，已加类型守卫。
* **400ms 重扫门限内的竞态**：轨道恰好在该窗口内挂上、此后 DOM 不再变化时，覆盖样式永远不会生效。
* **重新挂载会叠加第二份 `<style>`**，被第三方摘掉的标签也不会自愈；现在改为替换，缺失时自动补回。
* **排障钩子在轨道卸载后仍报告过期前缀**。
* **进场动画依赖样式表顺序**：改用自有 `@keyframes` 名 + `!important` + 减弱动效保护。

### 变更

* **一张表、一个策略**：四套并行字段清单与三层 store 收敛为 `FIELDS` + `createSettingsPolicy()`；每个设置项的默认值、区间、步进、归一化与界面行都出自同一处。`client.js` 970 → 830 行，`index.js` 32 → 14 行。
* **「恢复默认」**由逐字段 unset 改为一次写空用户层，同时清掉历史与未知字段。
* **测试 118 → 151 条断言**，测试桩忠实建模 `createSnapshotStore`（深冻结、同引用短路、通知时才落盘），并断言桩契约本身，避免这类 bug 再次隐身。
* 文档同步到 1.5.0 并精简，`design-notes` 522 → 273 行。
* `package.json` 移除 0.2.1-rc.2 中不存在的 `@deepseek-ai/dsh-client-runtime`。

### 说明

* 零运行时依赖、无构建步骤，需要 dsh 0.1.7 或更新。
* `npm test` 在零安装下跑两侧 `node --check` + **151 条断言**。
* 发布带 provenance attestation（已写入 Sigstore 透明日志）。
