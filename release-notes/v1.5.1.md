# v1.5.1 — a documentation release: Chinese-first README, screenshots, badges

**Install or upgrade:**

```bash
dsh plugin --profile web add dsh-chat-locator
```

Then restart `dsh web` once. Settings live in your browser since 1.4.0, so there is nothing to migrate.

### Changed

Nothing in `index.js` or `client.js` behaves differently from 1.5.0. This release exists so npm's package page shows the same README as the repository: npm renders the copy inside the published tarball, and a published package's contents cannot be replaced afterwards.

* **The README opens in Chinese.** The Chinese version is now the default `README.md`; English moved to `README.en.md`, with a language link at the top of both. `zh-CN/README.md` is gone — a single pair of READMEs, not two overlapping copies.
* **Screenshots.** Two captures now sit in the README: the settings page (`Settings → Conversation locator`), and the length gradient on the rail with the hovered tick at its longest. Sources live in `docs/images/`.
* **Badges.** The header row gained the Awesome DSH Plugin badge (this plugin is in that community list), and the powered-by-dsh badge moved from the bottom of the page up into that row.
* **Docs parity.** `CONTRIBUTING.md`, `.github/PULL_REQUEST_TEMPLATE.md` and the issue-template "Settings reference" link now point at the right README after the swap.
* **The "Web" qualifier is gone.** DSH runs in the browser and as the desktop app, so the title line, the intro, the platform badge, `package.json`'s description and the docs now say plain "DSH" instead of "DSH Web". The plugin itself is unchanged: it is a client-side plugin and works wherever the conversation rail does.
* **Screenshots in the community list.** A repo-root `screenshots.json` lists the two captures, so the Awesome DSH Plugin listing (awesome-dsh-plugin.com) shows them as a thumbnail strip on the plugin card. No PR is needed for this: the list reads the file straight from this repository.

### Notes

* Zero runtime dependencies, no build step. Requires dsh 0.1.7 or newer.
* `npm test`: 151 assertions, unchanged, nothing installed, all green.
* Published to npm by CI with a provenance attestation (Sigstore transparency log).

## dsh-chat-locator v1.5.1（简体中文）

**安装或升级：**

```bash
dsh plugin --profile web add dsh-chat-locator
```

装完重启一次 `dsh web`。设置从 1.4.0 起就住在浏览器里，没有别的要迁移。

### 变更

`index.js` 与 `client.js` 的行为与 1.5.0 完全一致。发这一版是为了让 npm 包页面显示与仓库相同的 README —— npm 渲染的是已发布 tarball 里的那份副本，而发布后的包内容无法替换。

* **README 默认改为中文。** 中文版现在是默认的 `README.md`，英文版移到 `README.en.md`，两边顶部都有语言链接。删除了 `zh-CN/README.md` —— 只留一对 README，不再有两份重叠的中文文档。
* **加了截图。** README 新增两张截图：设置页（`设置 → 对话定位条`），以及轨道上的长度渐变 —— 悬停那根最长、两侧依次收回。源图放在 `docs/images/`。
* **徽章。** 顶部徽章行加了 Awesome DSH Plugin（本插件已收录进那个社区列表）；powered-by-dsh 徽章从文末挪到了这一行。
* **文档一致性。** 互换后 `CONTRIBUTING.md`、`.github/PULL_REQUEST_TEMPLATE.md` 与 issue 模板里的「Settings reference」链接已改指正确的 README。
* **去掉了「Web」这个限定。** DSH 既有浏览器版也有桌面版，所以标题行、开篇、平台徽章、`package.json` 的描述与文档里现在只写「DSH」，不再写「DSH Web」。插件本身没变：它是客户端插件，有对话轨道的地方就能用。
* **社区列表里的截图。** 仓库根目录新增 `screenshots.json`，列出那两张截图，于是 Awesome DSH Plugin 列表（awesome-dsh-plugin.com）的插件卡片会以缩略图条展示它们。这一步不需要提 PR —— 列表直接从本仓库读这个文件。

### 说明

* 零运行时依赖、无构建步骤，需要 dsh 0.1.7 或更新。
* `npm test`：151 条断言，与 1.5.0 相同，零安装全绿。
* 由 CI 发布到 npm，带 provenance attestation（已写入 Sigstore 透明日志）。
