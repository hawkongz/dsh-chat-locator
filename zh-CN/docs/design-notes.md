## 🔍 问题所在

DSH Web 会沿着对话区右缘画一条轮次轨道 —— 每轮对话一枚刻度。它由 `@deepseek-ai/dsh-client-ui-chat` 的 `ChatView` 直接渲染进对话滚动容器（`TurnNavigator`），Slot 系统没有给它留座位，也没有对外暴露「粗细 / 轨道侧」这类配置。

摆在面前的路有两条：自己重画一条，或者认领已有的那条的样式。本插件走第二条。重画一条就得重新实现内置的跳转轮次、未加载轮分页与活跃轮跟随 —— 这三个功能很容易做错一点点，而用户立刻就会发现。叠加样式则把它们全部原样保住。

代价是耦合。插件必须知道轨道当前用的是哪个类名，而这个类名由构建器生成、随版本变化。所以插件在运行时发现它，而不是写死。

## 🔧 认领样式，而不是重画

`discoverRail()` 在活动 DOM 上按模式发现 CSS Module 的真实类名前缀：找 `[class*="_frame"]`，并要求它同时含 `.<前缀>_mark` 子节点。实测前缀是 `eGxaPq`，但没有任何东西依赖这个具体值。

`railStyleText(prefix, config)` 再按用户配置生成覆盖规则。每条声明都带 `!important`，这是刻意的：插件在页面启动期就注入样式表，可能早于 `ui-chat` 自己的样式表，所以规则不能靠插入顺序取胜。

轨道还没渲染时 —— 不足两轮、窄容器、其它会话视图 —— 插件不抛错，也不密集轮询。一个 400ms 节流的 `MutationObserver` 会在轨道出现后补上规则，前缀变化时重新计算。

## 💾 设置住在浏览器里，不住在宿主半侧

1.3.0 及以前，插件有两个活着的半侧。宿主半侧 `index.js` 只做一件事：`ctx.settings.register('chat-locator', schema)`，schema 里带默认值与范围校验。浏览器半侧再用 `ctx.settingsScope.bind({ namespace: 'chat-locator' })` 绑定上去，于是每次改动都写进 DSH 设置文档，撑得过一切 —— 包括换一台机器。

dsh 0.1.7 移除了客户端 `settingsScope` 服务（设置持久化改走 remote.settings 体系），宿主半侧存在的唯一理由随之消失。1.4.0 起，浏览器半侧改用 `@deepseek-ai/dsh-client-store` 的 `createSnapshotStore` 加 `persist: { name: 'dsh.chat-locator.settings' }` 自建一个同形作用域。它与旧作用域的接口完全一致 —— `getSnapshot()` / `subscribe()` / `set()` / `unset()` —— 所以 `LocatorPolicy` 除了构造函数换了个参数，一行没改：

* `getSnapshot()` 返回 `{ value, status: 'ready', writable: true }`，且 `value` 恒含全部 schema 字段，缺键补默认值；
* `set(field, value)` 直接写穿到本地存储；
* `unset(field)` 删键，下一次快照回退默认值 —— 「恢复默认」走的就是这条路，它从不把默认值当值写回去。

### 代价

* **设置按浏览器各存一份。** 它住在当前浏览器的本地存储里，撑得过浏览器与 DSH Web 的重启，但不再跨浏览器、跨 profile、跨设备同步。
* **旧的宿主设置被忽略。** 1.3.0 及更早版本留在 DSH 设置文档里的 `chat-locator:` 段不再被读取，升级后首次打开看到的是出厂值。这是这次迁移被接受的代价，两份 README 都已写明。
* **会话暂存机制随之删除。** 本地作用域不存在「宿主还不认识这个字段」的状态，所以 `pending` 表、`unsupported` 状态、hostLegacy 提示与补写逻辑都被移除，没有留成死代码。`LocatorPolicy` 现在只有 subscribe → adopt → update → reset。

### `index.js` 为什么还在

`cordis.patch.yml` 把插件行（`name: 'dsh-chat-locator'`）解析到包入口 `main: ./index.js`，删掉它整行插件都会挂不上。所以 1.4.0 起它是一个写明了理由的空桩：不注册设置、不解析 schemastery、不挂任何宿主服务。过去支配开发节奏的「宿主半侧改动要重启 `dsh web`」规则，对任何可观测量都不再适用 —— 唯一活着的代码是浏览器半侧，页面刷新即生效。

## 💬 预览保持纯文本

悬停预览的正文完全来自内置的轮次大纲 —— `turnOutline` 投影加上已加载窗口的导航项。插件不引入任何其它文本来源。具体来说：

* 只取文本块。思考内容不是 text 块，所以它是**从结构上**进不了预览，而不是靠过滤拦掉的。
* 所有空白串（`\s+`）折叠成单空格，所以预览里不可能出现空白行。
* 按固定的字符预算加省略号截断（提示词 50、回复 120）。

插件只决定这份预览显示几行、字号与宽度多大、卡片多高、往哪一侧展开。`white-space: normal` 与 `overflow-wrap: anywhere` 把两个本会复发的失效方式钉死：换行产生的空行，以及横向溢出。

## 📐 长度渐变曲线

指针下的那根刻度最长，两侧依次收回内置宽度：

| 距悬停处 | 0 | ±1 | ±2 | ≥3 |
| :--- | :--- | :--- | :--- | :--- |
| 宽度 | 32px | 21px | 14px | 12px |
| 每格递减 | — | 11px | 7px | 2px |

这张表由 `buildGradientWidths()` 按幂曲线算出：

```js
12 + 20 * Math.pow(1 - d / 3, 2)   // d = 距悬停处的格数，0..2
```

得到的是一条**凸向轨道的弯钩**：紧挨悬停那格掉得最多，之后越来越缓，最后贴着轨道收尾。两个互相独立的旋钮各管一件事：`GRADIENT_REACH` 是档数，同时是曲线的分母 —— 所以少一档时中间档位会跟着重算，而不是简单砍掉最后一档；`GRADIENT_CURVE_EXPONENT` 管弯曲程度，`1` 是直线、`2.5` 是断崖。两者当前都是 `2`，这是巧合，不是耦合。

锚点是**悬停（预览）那根**（`_markPreview`），不是选中的轮次。当前轮的刻度（`_markActive`）宽度永不被改写。

### 0.1.7 的选择器重写

1.3.0 及以前，内置轨道给每根刻度套了一个 `_markPosition` 包裹层，距离选择器沿着这些包裹层的相邻兄弟链走（`:has(.P_markPreview) + .P_markPosition + .P_markPosition .P_mark::before`）。**dsh 0.1.7 删掉了这个包裹层**：刻度现在是 `div.P_marks` 下互为相邻兄弟的 `button.P_mark`，悬停那根自己带 `P_markPreview`。整条距离链于是静默匹配空规则 —— 渐变消失了，而任何地方都不报错，这正是运行时类名发现抓不到的失效模式（发现只检查 `_frame` + `_mark`，这两个都还在）。

选择器按新结构重建：「下方第 d 格」是 `.P_markPreview + .P_mark[+ .P_mark]::before`，「上方第 d 格」用 `.P_mark:has([+ .P_mark] + .P_markPreview)::before` 从候选刻度反向指回悬停刻度。

0.1.7 还改了刻度的量法：`::before` 从「写死宽度」变成 `width:20px` 加按状态取的 `scaleX(.6/.9/1)`。只改 width 会被内置缩放再乘一次（32px 渲染成 28.8px），所以插件发出的每条宽度规则现在都同时钉住 `transform:translateY(-50%)` —— 去掉 scaleX，宽度才是字面值，这与 0.1.7 之前的语义一致；`transform-origin` 随之失去意义。

### 渐变开关

渐变是装饰性的 —— 没有它轨道照样完整工作 —— 所以它有独立的一行设置（`gradient`，默认开），不像 1.3.0 删掉的「悬停预览开关」。关掉时整族宽度规则消失，**框架加宽也一起撤掉**：没有 32px 尖端要画，框架就保持内置 28px，不为不存在的东西白占那条隐形交互带。粗细、轨道侧与预览规则不受影响，设置页小样也跟着同一个开关走。

### 调参记录

幂次是照着真实截图调出来的，每个值都记下来，让推理过程能活下来：

| 幂次 | 邻居宽度（±1、±2） | 结论 |
| :--- | :--- | :--- |
| 2.5 | 24、17 | 首格掉 15px —— 像断崖，不像曲线。 |
| 1.5 | 23、16 | 平缓，但邻居太长，悬停那根不够突出。 |
| **2.0** | **21、14** | 当前这版。首格 11px —— 仍落在「有弯但不陡」的 9–12px 区间，而悬停那根是邻居的 1.52 倍。 |

### 裁剪盒

有很长一段时间，悬停那根看起来一点都不突出，而根源不在曲线。内置轨道框架宽 28px，而框架里的滚动容器带 `overflow-y: auto`；按 CSS 规范，另一轴的 `visible` 在这种情形下会折算成 `auto` —— **框架就是刻度的裁剪盒**。任何超过 28px 的尖端都会被裁掉，曲线于是退化成一截很短的斜线。

所以插件把框架加宽到「最长刻度 + 4px」（当前 32 + 4 = 36px）。刻度是右对齐的，所以位置一点没动，多出来的宽度只是裁剪余量。框架同时也是轨道的悬停与点击面 —— 这是唯一的可见副作用，见[已知边界](#-已知边界)。

## ✅ 验证状态

`node test/verify-client.mjs` 跑 **125 项断言**，全绿，不需要联网、不需要浏览器、不需要安装依赖。覆盖范围：

* **轨道发现** —— 含诱饵框架、无轨道、无 `document`。
* **长度渐变** —— 宽度表 `32 / 21 / 14`、递减量 `11 / 7 / 2` 及其单调性、**首格钉在「有弯但不陡」的 9–12px 区间**、最长刻度不超过框架宽度、框架宽度 = 峰值 + 4 = 36px、每侧影响 2 格、第 3 格起沿用 `12px`、`_markActive` 不被改写。
* **0.1.7 的选择器形态** —— 距离规则沿相邻兄弟 `.P_mark` 链（下方）与 `:has()` 反向指（上方），以及每条宽度旁的 `transform:translateY(-50%)`（内置 `scaleX` 不许再乘）。
* **渐变开关** —— 关掉后整族宽度规则与框架加宽一起消失，粗细、轨道侧与预览规则不动；设置页小样跟随开关（全部刻度回 12px、卡片贴边量收窄、注脚换成关闭说明）。
* **覆盖样式生成** —— 粗细、左右侧、高度变量随行数与字号变化、`line-clamp`、字号与行高成对改写、容器夹取宽度、花括号配平，以及不出现 `undefined` / `NaN`。
* **配置归一化** —— 越界夹取、非法值回落、默认值判定。
* **本地设置作用域（桩 `createSnapshotStore` + localStorage 后背）** —— 构造时反序列化已存值、缺键补默认、每次改动写穿、以及「恢复默认」背后的七字段 `unset`。
* **用桩服务跑完整 `apply()`** —— 字典注册、本地作用域构造、覆盖样式挂载与随配置刷新、设置页注册（含 `order`），以及清理。
* **直接把设置页组件跑一遍** —— 小样 7 根刻度、长度序列 `12 / 14 / 21 / 32 / 21 / 14 / 12`、预览卡让开最长刻度 48px、卡片高度 144px / 198px / 252px，以及字号、宽度、行数跟随配置。

`index.js` 自 1.4.0 起是空桩，只由 `node --check` 覆盖；它过去承担的行为（schemastery 解析与设置注册）没有替代物可测。

**未验证，而且你应该知道：** 像素级的观感 —— 曲线渐变的实际弧度、字号与宽度的手感 —— 机器没有检查过，因为开发环境里没有浏览器自动化能力。这些请你用眼睛判断。本地存储迁移（设置值撑过一次浏览器重启）与 0.1.7 选择器重写（32 / 21 / 14 / 12px 重新可见）在 1.4.0 收尾时都在活的 DSH Web 实例上手工过过；自动化套件只覆盖同一批代码路径的桩版本。

## 🚧 已知边界

* **与上游的耦合。** 唯一的结构约定是「`<前缀>_frame` 里有互为相邻兄弟的 `<前缀>_mark` 按钮」，加上悬停那根自己带的状态类名 `_markPreview`。0.1.7 之前距离选择器依赖的 `_markPosition` 包裹层已被上游删除，不会再回来。若上游改掉这些名字，长度渐变会静默失效 —— 不报错，也不影响对话本身。
* **长度渐变依赖 CSS `:has()`**（Chromium 105+ 起支持）。不支持的浏览器只是这几条不生效，长度回到内置值。
* **容器宽度 ≤ 900px 时轨道自己隐藏**，这是 shipped 的 `@container` 规则。本插件不强行夺回。
* **粗细上限 8px**，因为刻度行高固定 10px，再粗会互相压住。
* **加宽框架有副作用。** 为了让 32px 的尖端不被裁掉，框架从 28px 变成 36px —— 但仅限渐变开着的时候。框架本身就是轨道的悬停/点击面，所以对话区右侧那块**隐形交互带**跟着宽了 8px：在那一带里悬停会浮出预览卡，点击会跳到对应轮次。关掉渐变会一并撤掉加宽，交互带回到内置宽度。
* **预览字号/宽度只作用在预览卡上。** 字体不是内置轨道的字体，宽度也不改轨道本身占用的 28px 布局空间，所以调大不会挤到正文。
* **距悬停处第 3 格起不改长度。** 保持内置宽度 —— 普通轮 12px、未加载轮 8px、当前轮 20px —— 这样轨道整体观感不变。
* **挂载 bundle 需要重启宿主。** 插件树在启动时合成，所以安装、卸载或重新启用 bundle 都要等 `dsh web` 重启一次才生效 —— 只刷新浏览器不够。（设置本身不再等任何东西：1.4.0 起它就是浏览器本地的。）

## 📚 版本记录

### 1.4.0

* **设置搬进浏览器。** dsh 0.1.7 移除了客户端 `settingsScope` 服务，浏览器半侧改用 `createSnapshotStore`（`@deepseek-ai/dsh-client-store`）把配置持久化在本地存储键 `dsh.chat-locator.settings` 上。设置撑得过浏览器重启，但不再跨浏览器 / 跨设备同步；旧版本留在 DSH 设置文档里的 `chat-locator:` 段会被忽略 —— 升级后首次打开看到出厂值。「恢复默认」仍旧逐字段 `unset`。
* **宿主半侧变成空桩。** 没有什么要注册的了，`index.js` 只因 patch 行解析到它而保留；schemastery 这个 peer 依赖一并移除。
* **渐变选择器按 0.1.7 重写。** 内置轨道删掉了 `_markPosition` 包裹层 —— 刻度变成互为相邻兄弟的 `button.P_mark` —— 于是每条距离规则都匹配空规则，曲线静默消失。现在下方沿相邻兄弟链走、上方用 `:has()` 反向指；并且每条宽度规则都钉住 `transform:translateY(-50%)`，因为 0.1.7 按 `20px × scaleX(.6/.9/1)` 量刻度，不再给死宽度。
* **长度渐变有了自己的开关。** 它是装饰 —— 关掉只是回到内置外观，轨道、跳转、分页与预览都不受影响 —— 所以 `gradient`（默认开）进了设置页、小样与「恢复默认」。关掉它同时撤掉框架加宽：没有 32px 峰值需要余量。
* **死代码清理。** 会话暂存（`pending`）链路、`unsupported` 状态、「宿主设置文档不可用 / 只读 / 旧版」三条提示及其文案、补写逻辑全部移除。`LocatorPolicy` 现在只有 subscribe → adopt → update → reset，排障钩子也不再报告设置状态。

### 1.3.0

* **去掉「悬停预览」开关。** 定位条的存在意义就是浏览，而一个能关掉预览的开关恰好与它自己的用途相悖 —— 关掉之后轨道只剩下一排刻度位置。现在预览、长度渐变、设置页小样都恒定生效。唯一保留的总开关是「显示对话定位条」（隐藏整条轨道）。`preview` 字段已从设置 schema 移除；设置文档里残留的 `preview: false` 会被忽略，不做迁移。

### 1.2.0

1. **长度渐变加长、改成曲线，并把裁剪盒打开。** 渐变从 4 档（24 / 20 / 16 / 12）扩到 6 档，再按两轮「减少一级」收到现在的 4 档（32 / 21 / 14 / 12），每侧影响 2 格。档位由幂曲线算出，框架宽度从 28px 覆盖成 36px 以免峰值被裁掉。锚点是悬停（预览）那根，当前轮的宽度不被改写。
2. **加了预览字号与预览框宽度。** 字号与行高成对改写，因为内置行高是固定 px，只改字号会把行挤在一起。卡片高度按 `46px + 行高 × 行数` 计算：12px / 3 行正好等于内置的 100px（默认外观不变），18px / 6 行是 208px。宽度沿用内置写法 `width: min(Npx, 100cqw - 120px)`，所以窄窗口不会把卡片顶出可视区域。
3. **加了「恢复默认」。** 六项逐字段 `unset` —— 清掉用户层、退回 schema 默认值，而不是把默认值再写一遍。当各项都已是默认值时，按钮置灰并如实说明。

### 1.1.0

* 预览行数真的生效了 —— 高度变量随行数与字号一起计算。
* 长度渐变锚在预览态，而不是选中轮。
